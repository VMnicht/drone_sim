# 模型控制器说明

## 软件边界

`ModelBasedController` 和 `MotorMixer` 位于 `drone_core`，只依赖 Eigen/STL。`position_controller_node` 仅负责：

- 接收 `/drone/odom` 和 `/drone/goal`；
- 将 ROS Odometry 转换为核心 `State`；
- 加载质量、惯量、推力系数和控制参数；
- 将核心输出转换为 `/drone/motor_rpm_cmd`；
- 发布 `/drone/reference` 供 RViz2 显示。

## 位置模型控制

控制器直接使用质量和重力模型计算世界系期望合力：

```text
e_p = p - p_d
e_v = v - v_d
a_fb = -K_p .* e_p - K_v .* e_v
F_d = m * (a_d + a_fb + g * e_3)
```

水平加速度、垂向加速度和最大倾角均有显式限制。该结构不是将位置误差直接经验映射为 RPM，而是先根据平动模型求期望合力。

## 几何姿态控制

期望机体 z 轴与 `F_d` 对齐，再结合期望 yaw 构造期望旋转矩阵 `R_d`。姿态误差为：

```text
e_R = 0.5 * vee(R_d^T R - R^T R_d)
e_Omega = Omega - Omega_d
```

使用惯量和刚体耦合补偿计算期望力矩：

```text
tau_d = -K_R .* e_R - K_Omega .* e_Omega + Omega x (I * Omega)
```

总推力是期望世界系合力在当前机体 z 轴上的投影，并受推重比限制。

## 电机分配

控制器和动力学共用同一个 X 型分配矩阵：

```text
[T, tau_x, tau_y, tau_z]^T = A * [omega_1^2, omega_2^2, omega_3^2, omega_4^2]^T
```

`MotorMixer` 计算 `A^-1`，对平方转速执行物理上下限后开方。动力学也通过同一个 `A` 计算实际 wrench，防止两侧电机编号或符号不一致。

## 安全限制

- 最大水平/垂向加速度；
- 最大倾角 35 度；
- 最大三轴力矩；
- 最大推重比；
- 电机最小/最大转速；
- Odometry 超时后输出零命令；
- 非有限状态、目标和控制输出拒绝。

## 当前悬停参数

默认目标为 `(0, 0, 1.5)`，位置增益 `[3, 3, 6]`，速度增益 `[3.5, 3.5, 4.5]`。姿态增益为 `[0.40, 0.40, 0.25]`，角速度增益为 `[0.16, 0.16, 0.10]`，最大倾角 25°。在零扰动、200 Hz 动力学、100 Hz 控制和 30 ms 电机一阶时间常数下，ROS2 实测 12 秒时：

- 高度约 `1.49974 m`；
- 垂向速度约 `5.3e-5 m/s`；
- 四电机约 `10820.79 RPM`；
- 姿态角速度接近零。

当前航点任务保持固定 yaw。测试发现位置切换时同时施加 90°/180° yaw 阶跃会产生明显姿态耦合和绕行，因此该用法不作为当前版本的有效验收场景。后续应对 yaw 生成限速轨迹，并补充期望角速度、角加速度前馈。
